## 4. 已知边界

- 当前只完整支持“云、雷、礼、明”；“风”字及其他 JieZi 图片不进入镜像、PostgreSQL 或 MinIO 演示目录；
- 当前向量是基于图片关联文字元数据生成的可重复 1024 维演示向量，尚不是经评测的视觉编码模型；
- JieZi 许可为 CC BY-NC-ND 4.0，仅限非商业研究，原始资料版权归各提供方；
- Compose 面向本地演示，没有账号和多租户能力，不得直接公网发布；
- 单字断代、争议覆盖和文化解释仍需领域专家审核。
