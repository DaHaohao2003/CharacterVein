## 4. 模型与外部服务

| 能力                         | 默认/可选实现                                                           | 说明                                                                             |
| ---------------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 任务解析、规划与检索问题生成 | 阿里云百炼 `qwen3.8-flash`；失败时 `DeterministicTextProvider`          | 模型提取任务并决定计划标题和检索问题；程序层校正目标字、工具契约、依赖与完成标准 |
| 传播内容生成                 | 阿里云百炼 `qwen3.8-flash`；失败时 `DeterministicTextProvider`          | 将任务、字形阶段和最多 24 条网络/用户资料片段提供给模型生成讲解                  |
| 联网搜索                     | [阿里云百炼联网搜索](https://help.aliyun.com/zh/model-studio/web-search/) 原生 DashScope `enable_search + enable_source` | 保存真实搜索标题、URL 和获取时间；搜索摘要与网页原文分开标注                    |
| 图片理解与字形视觉观察       | [阿里云百炼 `qwen3.8-flash`](https://help.aliyun.com/zh/model-studio/qwen3-8-flash)；未配置时安全降级 | 提取现代文字；观察已标注字形的可见特征，不识别未知古文字或判断传承               |
| 文献向量表示                 | 阿里云百炼 `text-embedding-v4`；失败时 `DeterministicEmbeddingProvider` | 每批最多 10 条；导入结果输出请求数和是否降级，确保文献与查询处于同一向量空间     |
| 图像目录向量                 | `DeterministicEmbeddingProvider`                                        | 仅用于图片关联文字元数据检索，不宣称为视觉编码模型                               |

参考资料用于给模型提供上下文、减少无依据补写；系统不逐句绑定来源、不执行事实核验，也不保证输出准确。API Key 只从 `.env` 注入，不进入数据库、前端或仓库。

## 5. 核心算法与开源组件

- LangGraph：工作流状态图、模型与工具编排、降级和 PostgreSQL 检查点；
- PostgreSQL 16 + pgvector：业务数据、参考片段向量和持久化状态；
- 混合检索：对当前任务快照执行结构化字段、PostgreSQL 全文和 pgvector 三路召回，以 RRF 融合；不叠加来源权威加分；
- FastAPI + SQLAlchemy + Alembic：API、数据访问与迁移；
- Next.js + React：Web 工作台；
- MinIO：用户上传对象存储；
- Pillow、pypdf、python-docx：受支持图片和文档的本地校验/解析。

具体依赖版本由 `uv.lock` 与 `pnpm-lock.yaml` 锁定。
