## 3. 演示证据边界

本轮 4 字的字形、结构、本义和演化摘要取自 JieZi 元数据，权威等级登记为 B；教育部文章只用于确定整体分期和主线/支线展示规则，不替代单字断代。图像目录检索使用基于图片关联文字元数据生成的本地向量，尚不把它表述为经过专家评测的视觉语义模型；文献混合检索在配置有效密钥时使用阿里云文本嵌入，并显式记录是否发生本地降级。后续补充单字文献、馆藏断代或专家审核时，新增来源必须单独记录许可和定位。

## 4. 模型与外部服务

| 能力 | 默认/可选实现 | 说明 |
|---|---|---|
| 任务规划与检索问题生成 | 阿里云百炼 `qwen-plus`；失败时 `DeterministicTextProvider` | 模型决定计划标题和检索问题；程序层校正工具契约、依赖与完成标准 |
| 陈述证据审校 | 阿里云百炼 `qwen-plus`；失败时本地确定性审校 | OpenAI 兼容接口；任务记录保存模型名、提示版本和是否降级 |
| 传播内容渲染 | `DeterministicTextProvider` | 只消费已审校陈述和阶段字段，避免模型补写未绑定的字源事实 |
| 图片展签 OCR | 阿里云百炼 `qwen-vl-ocr`；未配置时本地占位实现 | 只提取现代文字，不识别未知古文字 |
| 文献向量表示 | 阿里云百炼 `text-embedding-v4`；失败时 `DeterministicEmbeddingProvider` | 每批最多 10 条；导入结果输出请求数和是否降级，确保文献与查询处于同一向量空间 |
| 图像目录向量 | `DeterministicEmbeddingProvider` | 仅用于图片关联文字元数据检索，不宣称为视觉编码模型 |

模型输出仅作为辅助结果。事实陈述仍须绑定证据并通过审校；API Key 只从 `.env` 注入，不进入数据库、前端或仓库。

## 5. 核心算法与开源组件

- LangGraph：工作流状态图、条件回退和 PostgreSQL 检查点；
- PostgreSQL 16 + pgvector：业务数据、证据向量和持久化状态；
- 混合检索：精确命中、关键词覆盖和余弦相似度的加权排序；
- FastAPI + SQLAlchemy + Alembic：API、数据访问与迁移；
- Next.js + React：Web 工作台；
- MinIO：用户上传对象存储；
- Pillow、pypdf、python-docx：受支持图片和文档的本地校验/解析。

具体依赖版本由 `uv.lock` 与 `pnpm-lock.yaml` 锁定。
