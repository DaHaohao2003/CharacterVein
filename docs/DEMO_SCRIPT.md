# 五分钟比赛演示脚本

演示主案例使用“云”，结尾快速切换“雷、礼、明”证明流程和图 RAG 可复用。演示前运行阶段 5 冒烟脚本，并保留一个已完成任务作为网络异常备用。

## 0:00—0:40 复杂输入

输入：

> 为小学六年级制作一份 4 分钟的“云”字文化讲解，展示至少 3 个历史阶段，争议观点不要写成定论，并生成 2 道互动题。

说明系统只自动接受现代文字明确写出的目标字；未知古文字图形不会被擅自释读。

## 0:40—1:20 确认与计划

展示目标字、受众、时长、阶段数、互动题和争议约束。确认后进入三栏工作台，指出规划、混合检索、演化构建、证据审校、内容生成和约束检查六个节点。

## 1:20—2:30 演化认知与图 RAG

沿主时间线依次查看甲骨、金文、战国、篆、隶、楷代表图，再查看独立草书支线。强调：

- 图片来自 JieZi 原始 JPG/PNG，不是现代字体模拟；
- 四字共 328 张图存于 MinIO，328 条元数据和检索向量存于 PostgreSQL/pgvector；
- 可按汉字、书体和自然语言进行图片召回；
- JieZi 七类目录用于组织样本，不被描述成毫无分支的严格年代直线。

## 2:30—3:20 证据与边界

展开陈述，展示来源、原始路径、权威等级、许可和审校状态。指出系统把数据集事实与系统归纳分开；单图没有可靠断代时不作推测，草书不是楷书之后的下一代规范字形。

## 3:20—4:20 文化传播

展示小学六年级版讲解和两道互动题。对照约束面板确认目标字、主干阶段、互动题、证据绑定、审校、受众与时长全部通过。

## 4:20—5:00 动态修改、恢复与扩展

把时长改为 2 分钟并局部再生成，展示事实层哈希未变和新内容版本；导出 Markdown/HTML/JSON。刷新页面证明任务仍在。最后打开预先完成的“雷、礼、明”任务，说明其他 JieZi 数据暂不导入，待产品功能和专家审核流程稳定后再扩充。

## 异常备用话术

- 外部模型不可用：系统记录 `fallback_used` 并使用本地确定性审校；
- 页面断线：重新打开原任务 URL；
- API 节点中断：服务恢复后从最近检查点恢复；
- 现场网络不可用：4 字原图、元数据和向量均在本地 PostgreSQL/MinIO 卷中；
- 重新建容器：`glyph-seed` 幂等复用 328 个对象，不重复导入。
