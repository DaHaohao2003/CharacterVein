# 阶段 7 资料增强智能体评测规范

> 文档版本：v1.4
> 最后更新：2026-08-22

## 目标

阶段 7 不做模型基线对比、消融实验或事实核验评测。固定语料只验证工程回归；当前生产验收检查以下链路是否真实成立：

```text
Web / 当前任务 Upload
→ Reference Snapshot
→ Context Assembly
→ Glyph Retrieval
→ LLM Generation
→ Constraint Check
```

参考资料用于给大模型提供上下文、减少无依据补写。系统不逐句绑定来源，不判断资料或生成内容的真伪，也不承诺输出准确。

## 检索回归集

- 20 条黄金查询：云、雷、礼、明各 5 条；
- 覆盖数据集总览、甲骨文字形、金文字义/分期、楷书规范形和草书支线；
- 固定 fixture 的指标为 Recall@10，验收阈值为 95%；
- 每条结果记录结构化、关键词或向量通道排名以及 RRF 分数。

黄金查询固化在 `apps/api/tests/test_stage_seven_agent.py`。它们使用 `FixtureEvidenceProvider`、内存混合检索器和固定 68 条片段完成可重复回归。数据库中的 fixture 不进入生产 Reference Router；该指标不证明真实 Web Search 或真实用户资料上的检索质量。

## 智能体场景

| 场景       | 输入条件                         | 期望行为                                                        |
| ---------- | -------------------------------- | --------------------------------------------------------------- |
| 网络参考   | Web 返回当前任务相关正文片段     | 片段进入模型的 `reference_materials`，结果记录所用 `source_ids` |
| 用户资料   | 当前任务上传文档包含相关正文     | 只召回当前任务片段，不跨任务使用                                |
| 多来源     | Web 与 Upload 同时返回相关片段    | 两类片段共同进入上下文，不做支持或冲突裁决                      |
| 资料不足   | Web 不可用且没有可召回的上传资料 | 继续用字形和本地模板生成，标记 `reference_context=false`        |
| 模型不可用 | Qwen 请求或结构化校验失败        | 显式降级到确定性模板，事件和结果保留降级信息                    |
| 节点中断   | 工具第一次调用抛出异常           | 通过 LangGraph 检查点从失败节点恢复，不重复已完成节点           |

## 尚未完成的比赛级评测

以下指标不得描述为已经达到：

- 真实网络搜索的相关性、延迟和失败率，以及未来若增加网页抓取层时的正文获取成功率；
- 用户资料召回在更多格式、长文档和复杂查询上的效果；
- 教师或文化内容创作者对受众适配、可理解性和人工修改量的测试；
- 多次真实 Qwen 运行的平均端到端耗时、Token/费用和降级率；
- 参考资料增强前后生成幻觉率的人工对照评估；
- 断网、阿里云限流、API 重启和浏览器刷新组合场景；
- 公开部署条件下的并发、认证、限流、安全扫描与隐私评估。

下一轮优先完成四个核心案例的重复真实运行、端到端耗时与费用记录，并开展目标用户和文化内容创作者评测；若比赛规则要求展示网页原文，再增加受限抓取、正文抽取和安全过滤层。
